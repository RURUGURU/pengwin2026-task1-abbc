[Description] (max 1024 chars)
----------------------------------------------------------------
Pelvic and femoral fracture fragment instance segmentation in CT.

Pipeline:
1. Anatomy routing — the official spacing-based rule classifies each case as pelvic or femoral and crops per-anatomy ROIs (Sacrum, Left/Right Hipbone, Femur).
2. Per-anatomy semantic segmentation — nnU-Net v2 ResEnc-L trained with an Adaptive Border / Boundary / Core (ABBC) 4-class representation (background / border / boundary / core). A boundary-class weight on the CE+Dice loss biases the network toward sharper inter-fragment separation.
3. Instance decoding — core-seeded watershed converts the 4-class softmax into instance masks. Connected components below ~1 cm^3 are pruned per case spacing; an anatomy-size-ratio filter merges spurious tiny fragments.

Output: integer label map per PENGWIN convention (0 background; 1-50 sacrum; 51-100 left hipbone; 101-150 right hipbone; 151-200 femur). Sacrum and hipbone are modeled by the current network; femur extension is in progress.

GPU: T4 16 GiB. Inference patch 224x160x192 (~11 GiB peak).
----------------------------------------------------------------
