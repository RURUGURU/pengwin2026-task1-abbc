Per-Anatomy ABBC nnU-Net with Core-Seed Watershed (PENGWIN-Auto)
----------------------------------------------------------------
(64 chars, 의미 명확, "test/debug" 단어 미포함, 향후 컨테이너 교체 후에도 그대로 사용 가능)

[Description] (max 1024 chars)
----------------------------------------------------------------
Pelvic and femoral fracture fragment instance segmentation in CT.

Pipeline (two models, loaded serially on a single GPU):
1. Anatomy classifier — Dataset532_PelvicAnatomyV2 nnU-Net runs on the full CT to label Sacrum, Left/Right Hipbone, and Femur and to crop per-anatomy ROIs. The model is then released from GPU memory.
2. Per-anatomy fragment segmenter — Dataset537 V291 ABBC nnU-Net v2 ResEnc-L is loaded on the freed GPU and run per ROI. It uses a 4-class Adaptive Border/Boundary/Core representation (background/border/boundary/core); a boundary-class CE+Dice weight sharpens inter-fragment separation.
3. Instance decoding — core-seeded watershed converts the softmax into instance masks; components <~1 cm^3 are pruned and an anatomy-size-ratio filter merges spurious tiny fragments.

Output: integer label map per PENGWIN convention (0 bg; 1-50 sacrum; 51-100 L hipbone; 101-150 R hipbone; 151-200 femur).

GPU: T4 16 GiB. Peak = max(Ds532, V291), not sum (serial load). V291 patch 224x160x192 ~11 GiB.
----------------------------------------------------------------
