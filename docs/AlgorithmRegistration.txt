Anatomy-Routed ABBC-Affinity STU-Net Cascade (PENGWIN-Auto V2.0)
----------------------------------------------------------------
(method-level; reusable across container versions)


[Description] (max 1024 chars)
----------------------------------------------------------------
Pelvic and femoral fracture fragment instance segmentation in CT.

Two-stage cascade (two STU-Net-B models, loaded serially on one GPU):
1. Anatomy — Dataset539_PelvicFemurAnatomyV3 runs on the full CT, labelling Sacrum, Left/Right Hipbone and Femur (5-class).
2. Target-family routing — a lightweight random-forest router packaged with the model payload predicts pelvic vs femur from CT/FOV/bone-geometry features. Pelvic cases forward only Sacrum+LeftHip+RightHip to Stage B; femur cases forward only Femur.
3. Fracture — Dataset538 V308 ABBC+affinity STU-Net runs per target ROI using bone-LUT CT plus routing-derived anatomy context. It emits ABBC channels plus learned same-instance affinities.
4. Decoding — average-linkage agglomeration yields instance masks; ~1 cm^3 components are pruned and outputs are remapped to the official PENGWIN label ranges.

Backbone STU-Net-B (Apache-2.0) warm-started from a TotalSegmentator bone pretrain. Femur is fully modelled. V2.0 keeps the v1.5 STU-Net weights unchanged and only adds the post-anatomy target-family router.

Output: PENGWIN label map (0 bg; 1-50 sacrum; 51-100 L hip; 101-150 R hip; 151-200 femur).

GPU: T4 16 GiB. Peak = max(stage1, stage2), not sum (serial load); STU-Net-B ~4 GiB/stage.
----------------------------------------------------------------
