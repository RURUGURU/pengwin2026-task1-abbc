Anatomy-Routed ABBC-Affinity STU-Net Cascade (PENGWIN-Auto)
----------------------------------------------------------------

[Description] (max 1024 chars)
----------------------------------------------------------------
Pelvic and femoral fracture-fragment instance segmentation in CT.

The method is a serial two-stage STU-Net-B cascade. Stage A is a refreshed-data
5-class anatomy model trained from scratch and predicts sacrum, left/right
hipbone and femur. A hybrid case-family router uses a random forest when
confident and the organizers' acquisition rule only as an uncertainty
tiebreak. Stage B is a 13-channel ABBC+9-affinity model initialized from the
official TotalSegmentator base_ep4k backbone and fine-tuned on refreshed PENGWIN
data. Average-linkage agglomeration at validation-selected T=0.75 converts the
affinities to fragment instances. Outputs use the official ranges: 1-50 sacrum,
51-100 left hip, 101-150 right hip and 151-200 femur.

The v3.4 candidate uses fold-0 checkpoint_best for both stages. The Stage-B run
ended after epoch 180 without checkpoint_final, so its valid best checkpoint is
packaged explicitly. Local 68-case official-aligned evaluation: Dice 0.8821,
HD95 3.261 mm, ASSD 0.775 mm and instance F1 0.9301.
----------------------------------------------------------------

[Job requires gpu type]
----------------------------------------------------------------
NVIDIA T4 Tensor Core GPU (16 GiB VRAM)

The two STU-Net-B models are loaded and released serially, so peak VRAM is the
maximum of a single stage rather than the sum of both stages.
