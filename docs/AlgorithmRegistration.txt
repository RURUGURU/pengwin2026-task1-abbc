Per-Anatomy ABBC STU-Net with Core-Seed Watershed (PENGWIN-Auto)
----------------------------------------------------------------
(method-level; reusable across container versions)


[Description] (max 1024 chars)
----------------------------------------------------------------
Pelvic and femoral fracture fragment instance segmentation in CT.

Two-stage cascade (two STU-Net-B models, loaded serially on one GPU):
1. Anatomy — Dataset539_PelvicFemurAnatomyV3 runs on the full CT, labelling Sacrum, Left/Right Hipbone and Femur (5-class) and cropping per-anatomy ROIs; then released from GPU.
2. Fracture — Dataset538 ABBC STU-Net is loaded on the freed GPU and run per ROI on a 3-channel input (bone-LUT CT, anatomy probability, signed distance). It emits a 4-class Adaptive Border/Boundary/Core field.
3. Decoding — core-seeded watershed yields instance masks; ~1 cm^3 components are pruned and a small-fragment merge removes spurious splits.

Backbone STU-Net-B (Apache-2.0) warm-started from a TotalSegmentator bone pretrain. Femur is fully modelled. Trained on a leakage-free case-grouped split shared by both stages.

Output: PENGWIN label map (0 bg; 1-50 sacrum; 51-100 L hip; 101-150 R hip; 151-200 femur).

GPU: T4 16 GiB. Peak = max(stage1, stage2), not sum (serial load); STU-Net-B ~4 GiB/stage.
----------------------------------------------------------------
