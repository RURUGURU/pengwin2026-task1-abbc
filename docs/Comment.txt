[V2.0 target-family router 2026-07-06] Two-stage STU-Net-B cascade for PENGWIN Task 1. Stage A is Dataset539 5-class anatomy STU-Net (Sacrum, LeftHip, RightHip, Femur). Stage B is Dataset538 V308 ABBC+9-affinity STU-Net, decoded with average-linkage agglomeration and mapped to the official label ranges (1-50 sacrum, 51-100 left hip, 101-150 right hip, 151-200 femur). V2.0 keeps the v1.5 STU-Net weights unchanged and adds a lightweight random-forest target-family router packaged with the model payload as stage1_router/stage1_target_router_fold0.joblib. The router uses CT/FOV/bone-geometry features to classify the case as pelvic or femur, then forwards only Sacrum+LeftHip+RightHip or only Femur to Stage B. On the local fold0 validation split (68 cases: 34 pelvic, 34 femur), this mainly removed wrong-family false positives: foreground Dice 0.7757->0.9761, Prec@0.5 0.5027->0.8485, F1@0.5 0.5568->0.7699, with IoU-F essentially unchanged (0.6827->0.6825). Runtime remains single-GPU, serial Stage A then Stage B, within the T4/10min budget.
